# Split specialist and orchestrator responsibilities

Status: Accepted

The `0.15.0` correction is a coordinated two-repository release with separate ownership and commits. AI UI Slop Bot owns style accounting, CSS attribution, Coverage Diagnostics, typed module facts, Source Roles, bounded static values, conditioned ownership, schema and baseline compatibility, and native qualification. SlopSweep owns disposable Scope Draft initialization and provenance, nested deadline margins, schema adaptation and recovery presentation, and corpus orchestration. A pinned-revision integration test joins the releases; neither project hides or compensates for behavior owned by the other.

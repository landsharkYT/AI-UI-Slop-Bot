# Stage discovery, Validated MVP, and Full V1

Status: Accepted

The project will use three explicit delivery gates: a disposable Discovery Prototype to test the riskiest technical and product hypotheses, a Validated MVP as the first usable local advisory release with two calibrated rules, and Full V1 for the complete nine-rule, broad-archetype, baseline-enforced, GitHub-integrated, native-platform product. This preserves the intended full-brunt V1 while preventing unvalidated rules, distribution work, and enforcement machinery from becoming prerequisites for learning whether users trust the core findings. Changed-file-only presentation, inline pull-request annotations, and a hosted GitHub App remain post-V1; Full V1 enforcement compares whole-repository results with a Reviewed Baseline.

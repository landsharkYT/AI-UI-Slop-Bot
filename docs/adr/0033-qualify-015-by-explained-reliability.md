# Qualify 0.15 by explained reliability

Status: Accepted

The `0.15.0` SlopSweep corpus gate does not require every applicable repository to report `complete`, because that target could reward hidden uncertainty. Qualification instead requires zero UI timeouts; no incomplete result caused solely by bounded above-floor limitations; concrete, attributable Blocking Coverage Loss for every remaining provisional review; correct external ownership and Source Roles; isolated Scope Drafts; rule-relevant style accounting; deterministic finite class and owner resolution; explained Finding ownership changes; byte-equivalent repeated reports; existing performance and memory bounds; and deterministic recovery guidance for every blocker. Most current incomplete reviews are expected to become complete with limitations, but a justified incomplete result is safer than a manufactured pass.

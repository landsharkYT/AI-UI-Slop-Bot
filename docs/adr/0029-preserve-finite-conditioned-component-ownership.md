# Preserve finite conditioned component ownership

Status: Accepted

A statically finite component registry or dynamic component selection will produce a Conditioned Ownership Set rather than an unresolved edge merely because one unique owner cannot be selected. The repository graph records conditioned edges to every provable local owner, Findings remain attached to their defining owners, and parents retain condition-specific impact evidence. Arbitrary HOCs, unbounded runtime registries, and transformations that do not preserve identity remain localized coverage limitations; the scanner will not guess ownership from names or directory proximity.

# ADR 0021: Require coherent convergence evidence

Status: Accepted

Date: 2026-07-30

## Decision

Rule pack `1.0.0-beta.6` requires Framework Default Convergence signals to coexist as one coherent eligible display recipe in each participating owner. Cross-owner recurrence contributes to the Repository Profile but no longer inflates the intrinsic Finding score.

Template Convergence recognizes page owners by component identity rather than page-like filenames. Bento evidence requires explicit spanning. A three-card feature structure requires an explicit three-column grid with exactly three direct elements, so generic equal-column and command grids remain outside both patterns. Dialog descendants are excluded from persistent decoration and framework convergence.

Every reported signal selects evidence from an element that actually produced that signal. A static empty Tailwind v3 `plugins` array is resolved configuration, not dynamic coverage loss.

## Context

A read-only EventCardSite audit exposed technically reproducible but unhelpful findings. Framework traits spread across unrelated elements were unioned into a fictional recipe and then recurrence was counted in both Finding and Repository scores. Helper components inherited page status from their filename. Ordinary work grids were labeled bento or feature templates. Dialog elevation was treated like persistent page decoration, and evidence snippets often pointed at the first owner element rather than the source of the claimed signal.

Those errors made the output look more certain than its evidence justified.

## Consequences

- EventCardSite falls from 31 mixed findings to six coherent Control Surface Homogenization findings.
- Existing baselines require semantic migration review because rule IDs remain stable while their contracts and fingerprints change.
- Conservative structure rules may miss bento layouts expressed through abstractions the scanner cannot resolve. That is preferable to calling every grid a stock template; future recall changes need labeled positive fixtures.
- Customer calibration remains necessary. This decision improves evidence coherence, not the objectivity of aesthetic judgment.

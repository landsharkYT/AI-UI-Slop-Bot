# Make coverage diagnostics canonical and attributable

Status: Accepted

Coverage diagnostics will be structured canonical report records rather than aggregate prose strings. Each record carries a stable reason code, limitation or blocking-loss classification, affected path and location where available, affected style units or graph edges, active rule or signal relevance, resolved and unresolved counts, boundedness, deterministic recovery guidance, and capped representatives with an uncapped total. This schema expansion lets orchestrators and coding agents distinguish localized review work from evidence that invalidates the review while keeping Coverage Diagnostics separate from UI Findings.

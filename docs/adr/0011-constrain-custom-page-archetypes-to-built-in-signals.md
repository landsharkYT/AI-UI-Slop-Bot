# Constrain custom Page Archetypes to built-in structural signals

Status: Accepted

Repositories may extend the Page Archetype taxonomy through schema-validated definitions composed only from versioned built-in structural-signal identifiers, with required, supporting, excluding, and bounded-threshold fields allowed by the fixed Template Convergence contract. These definitions may alter classification and Template Convergence context but cannot add extractors, signals, patterns, score formulas, arbitrary expressions, or executable behavior. Canonical reports embed normalized definitions and fingerprints for reproducibility, preserving an open taxonomy without turning configuration into an external rule DSL.

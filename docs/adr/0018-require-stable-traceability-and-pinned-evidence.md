# Require stable traceability and pinned evidence

Status: Accepted

Every normative requirement and numbered release criterion will receive a stable semantic identifier mapped to its first required milestone, verification method, durable evidence record, and current status, with a source digest and automated consistency checks preventing stale, missing, or duplicate coverage. Performance claims use a committed, pinned runner and fixture specification rather than an unstable “standard runner.” The native scanner and target project require no Node.js, while GitHub-managed action services may use their bundled runtime internally. This package turns the requirements into an auditable implementation contract and makes acceptance results reproducible enough to compare.

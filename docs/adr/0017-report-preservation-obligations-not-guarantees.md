# Report Preservation Obligations, not guarantees

Status: Accepted

Refactoring Briefs will represent component APIs, semantics, interaction attachment, navigation, state, responsive behavior, and project-specific constraints as Preservation Obligations labeled observed, configured, or unknown, each with evidence and independent verification expectations. The scanner may identify existing verification procedures statically but never executes them, and neither a suggested cleanup nor a lower AI Slop Score proves runtime equivalence. Agent trials pass preservation only through applicable tests, configured checks, and human review, keeping the scanner useful without overstating what source analysis knows.

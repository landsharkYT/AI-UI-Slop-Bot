# Gate rule implementation on Rule Contracts

Status: Accepted

Every Slop Pattern must have an approved, versioned Rule Contract before its implementation begins, covering analysis scope, signals and exclusions, calculation behavior, House Style effects, score and coverage behavior, report evidence, and boundary-oriented Calibration Cases. The Discovery Prototype implements Repeated Decorative Shell; the Validated MVP adds Effect Stacking because it exercises contextual co-occurrence without depending on page classification; and Full V1 remains responsible for all nine rules. This gate prevents evocative rule names from being mistaken for executable requirements and makes rule behavior independently testable before the complete engine amplifies ambiguity.
